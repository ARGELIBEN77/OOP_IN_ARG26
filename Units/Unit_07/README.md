# Unit 7 — Inheritance and Binding

This unit builds class hierarchies and introduces the relationship between
static type, dynamic type, and function binding.

## Learning outcomes

After completing this unit, you should be able to:

- design a public-inheritance hierarchy that expresses an is-a relationship;
- distinguish static type, dynamic type, and binding time;
- override a virtual operation with a matching signature;
- explain and prevent slicing and unsafe base-class destruction.

## Main ideas

- Base and derived classes
- Public inheritance and substitutability
- Overriding and virtual functions
- Object slicing and virtual destructors
