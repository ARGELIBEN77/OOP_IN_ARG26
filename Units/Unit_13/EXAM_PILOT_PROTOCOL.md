# Exam Timing Pilot Protocol

Coverage and code correctness can be checked in the repository, but student
completion within 180 minutes requires a pilot.

## Participants

Ask two or three people whose knowledge is close to the target students. If
only a teaching assistant is available, allow for the fact that an expert will
normally work faster.

## Procedure

1. Provide only the student exam and the intended permitted materials.
2. Do not explain questions after timing begins; record clarification requests.
3. Record start and finish time for every question.
4. Mark responses with the planned rubric.
5. Ask which wording, code, or workload caused avoidable delay.

## Decision rules

- A prepared target student should retain time to review the work.
- If several participants misunderstand one sentence, revise its wording.
- If one question consumes disproportionate time, reduce its implementation
  load or points.
- Recheck that point allocations sum to 100 after every revision.
- Repeat an affected question with a new participant after a major change.

Record the pilot date, participant profile, median time, revisions, and final
approval below. Until those data exist, describe the exam as designed for 180
minutes rather than empirically validated.
