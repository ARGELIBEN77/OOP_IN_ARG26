# How to Use the Practice Assessments

The two practice examinations are deliberately different. A real examination
cannot test every course detail in three hours, so use both exams together and
use the review bank for targeted practice.

## Practice examination 1

This exam emphasizes ownership transfer, runtime polymorphism, the Rule of
Three, operator implementation, templates, iterators, lambdas, exceptions,
and integrated class design.

## Practice examination 2

This exam emphasizes copying and stack unwinding, UML relationships, static
members, resource-management diagnosis, checked operators, class templates,
custom iteration, STL container selection, and shared ownership.

## Recommended process

1. Solve one exam under a 180-minute limit without solutions.
2. Mark each answer as confident, uncertain, or incomplete.
3. Compare your reasoning with the corresponding solution.
4. Use the review bank only for concepts that caused difficulty.
5. Correct the answer from memory the next day.
6. Solve the second exam under the same conditions.

## Final readiness check

Before the examination, make sure you can do all five kinds of work:

- **Trace:** construction, copying, moving, exceptions, and destruction.
- **Diagnose:** compilation, ownership, slicing, overriding, and bounds errors.
- **Implement:** classes, operators, templates, iterators, and exception-safe
  operations.
- **Design:** relationships, ownership models, and suitable STL containers.
- **Explain:** justify behavior using precise C++ and OOP terminology.

Do not memorize the supplied solutions. Change names, values, and types, then
solve the altered problem again.
