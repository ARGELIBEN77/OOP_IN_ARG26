# Course Units

This directory organizes the 13-unit course sequence. Each unit directory is a
home for its lecture notes, examples, classroom activities, exercises, and
supporting resources. Project code remains in the independent project
directories at the repository root and is linked from the relevant units.

| [Unit 3](Unit_03/README.md) | Constructors and initializer lists | Song Class Fundamentals |
| [Unit 4](Unit_04/README.md) | Object lifetime and destructors | Song and Playlist projects |
| [Unit 5](Unit_05/README.md) | Working with objects and object relationships | Product Catalog and Shopping Cart |

| [Unit 9](Unit_09/README.md) | Exception handling | Music Store project |
