## How to study a unit

1. Read the unit page and its learning goals.
2. Work through the lecture examples.
3. Open the related project and follow its recommended reading order.
4. Predict the demonstration output, then build and run it.
5. Read the tests to identify the expected behavior.
6. Complete the exercises by changing or extending the project.
