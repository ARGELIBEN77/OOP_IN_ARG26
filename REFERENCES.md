# Course References

The course combines recent C++ books with authoritative online references.

## Books

- Marc Gregoire, *Professional C++*, 6th edition, Wiley, 2024. Units 4–12,
  especially resource management, OOP design, templates, smart pointers, and
  the Standard Library.
- Josh Lospinoso, *C++ Crash Course*, 2nd edition, No Starch Press, 2024.
  Units 1–12; practical coverage of classes, ownership, templates, and standard
  containers.
- Bjarne Stroustrup, *A Tour of C++*, 3rd edition, Addison-Wesley, 2022. Units
  7–12; concise language and Standard Library context.
- Nicolai M. Josuttis, *The C++ Standard Library*, 2nd edition,
  Addison-Wesley, 2012. Units 10–12; detailed container, iterator, algorithm,
  and smart-pointer reference.
- David Vandevoorde, Nicolai M. Josuttis, and Douglas Gregor, *C++ Templates:
  The Complete Guide*, 2nd edition, Addison-Wesley, 2017. Unit 10; selected
  introductory material.

## Online references

- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines),
  maintained by the Standard C++ Foundation. Units 1–12; design, interfaces,
  ownership, and resource safety.
- [cppreference](https://en.cppreference.com/w/cpp), an actively maintained
  language and Standard Library reference. Units 9–12; exceptions, templates,
  memory utilities, containers, iterators, algorithms, and lambdas.

Online references support precise API lookup but do not replace the guided
unit explanations and examples.
