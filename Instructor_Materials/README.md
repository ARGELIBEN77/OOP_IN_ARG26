# Instructor Materials

This directory keeps marking guides and worked solutions separate from the
student-facing units and projects.

## Available material

- [Unit 13 practice-examination solutions](Unit_13/PRACTICE_EXAM_SOLUTIONS.md)

Future project solutions should use the same exercise numbers as their
student files and include reasoning, a minimal implementation, common errors,
partial-credit guidance, and any additional tests.

This repository is public. These materials are organizationally separate but
not confidential. Restricted solutions should be kept in a private repository
or the institution's learning-management system.
