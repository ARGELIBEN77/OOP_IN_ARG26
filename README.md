# OOP in C++ — Course Repository

**Student website:** [argeliben77.github.io/OOP_IN_ARG26](https://argeliben77.github.io/OOP_IN_ARG26/)

This educational repository supports the C++ Object-Oriented Programming
course at Ramat Gan Academic College, developed by Dr. Elina Benenson
Opalinsky. It is designed for learners who have completed one procedural C++
course and are beginning object-oriented programming.

## Start here

Open the [Student Guide](STUDENT_GUIDE.md). It explains how to move from a
unit's lecture notes to its demonstration, tests, exercises, and self-check
guidance.

## Course units

The [Units directory](Units/README.md) organizes the 13-unit learning sequence
and connects each unit with its related projects.

## How to use a project

1. Read its learning goals and build instructions.
2. Predict the demonstration output.
3. Build and run the program and tests.
4. Read the source in the recommended order.
5. Complete the exercises before opening solution guidance.

Each project is independent and has its own source files, build instructions,
exercises, and tests.
