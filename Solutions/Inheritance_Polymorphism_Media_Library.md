# Inheritance and Polymorphism Media Library — Self-Check Guidance

- Exercises 1–3: identify base and derived roles, then determine static and
  dynamic type before selecting the invoked operation.
- Exercise 4: add `override`; the compiler should expose the signature error.
- Exercise 5: a new derived type should require no type test in the library.
- Exercise 6: a pure virtual operation prevents direct base-class objects.
- Exercise 7: store or pass through references or pointers to avoid slicing.
- Exercise 8: destruction through a base pointer requires a virtual destructor.
- Exercise 9: separate polymorphic access from ownership; a raw pointer may be
  non-owning when another object clearly controls lifetime.
- Exercise 10: evaluate the extension by how little existing processing code
  must change.
