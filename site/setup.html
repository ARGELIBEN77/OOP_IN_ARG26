Work with the code

Repository setup

You need Git, Make, and a compiler that supports C++17. The same commands work in Linux, macOS, and WSL.

Get the course files

git clone https://github.com/ARGELIBEN77/OOP_IN_ARG26.git
cd OOP_IN_ARG26

You may also use GitHub’s Code → Download ZIP option if you do not yet use Git.

Build one project

cd Song_Class_Fundamentals
make run
make test

Use the exact commands in the project README because some projects provide additional demonstrations.

A useful workflow

PredictWrite down what you expect before compiling.
RunCompare the real output with your reasoning.
ChangeMake one focused modification.
TestRun the test suite after every change.

When compilation fails

Start with the first error message. Confirm that you are inside the correct project directory and record the command, compiler version, and complete first error if you need help.
